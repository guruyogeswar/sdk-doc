LIMBIC Engine

A C++17 cognition engine for NPCs and agent simulations. Every agent runs a biologically-grounded brain — emotions, drives, memory, neuromodulators, social cognition, and reinforcement learning. Behaviour emerges from internal dynamics; no behaviour trees, no scripts.

What this is

LIMBIC is not a behaviour tree. It is not a planner. It is not a finite state machine. It is a simulated brain that runs once per tick, per agent, through a fixed seven-stage pipeline. The host game owns the world; LIMBIC owns the mind.

Note Your game pushes percepts in, calls tick(), reads the agent's decision out, and reports an outcome. The engine handles emotional dynamics, drive homeostasis, memory formation, neuromodulator regulation, action selection in the basal ganglia, and dopamine-driven learning.

A minimal example

my_game.cpp C++
#include "limbic/limbic_engine.hpp"
using namespace limbic::sdk;

int main() {
    EngineConfig cfg;
    cfg.preset     = Preset::COGNITIVE;
    cfg.max_agents = 100;
    auto engine = LimbicEngine::create(cfg);

    engine.register_action("forage", TAG_RESOURCE | TAG_SURVIVAL);
    engine.register_action("trade",  TAG_SOCIAL   | TAG_COOPERATIVE);

    AgentConfig ac{ .x=100, .y=100, .personality=Personality::MERCHANT };
    uint32_t npc = engine.spawn(ac);

    for (int i = 0; i < 300; ++i) {
        float energy = 0.8f;
        engine.perceive(npc, Percept::ENERGY_LEVEL, &energy, 1);
        engine.tick(0.016f);
        Decision d = engine.get_decision(npc);
        engine.report_outcome(npc, /*reward=*/ 0.3f, 5.f);
    }
}

How it differs from conventional NPC AI

ConventionalLIMBIC
Behaviour trees authored per roleBehaviour emerges from internal state
Memory bolted on as a scripting featureEpisodic hippocampal memory built in
Mood is a tag on a nodeMood is a continuous neuromodulator field
Relationships are integer reputation scoresPer-pair trust, threat, alliance, betrayal
Learning means hand-tuning constantsDopamine-RPE learning at runtime
