C++ API reference

The complete public surface of LimbicEngine, grouped by purpose. Defined in limbic/limbic_engine.hpp; all types in limbic/limbic_types.hpp.

Lifecycle

MethodReturnsDescription
LimbicEngine::create(cfg)LimbicEngineConstruct with the given EngineConfig. Move-only.
LimbicEngine::version()const char*SDK version string, e.g. "0.1.0".
tick(dt)voidAdvance all alive agents by dt seconds.
tick_agents(ids, n, dt)voidTick only the listed agents (LOD).
warmup(id, ticks)voidRun the brain forward without world time, post-spawn.
warmup_all(ticks)voidWarm every alive agent.

Population & groups

spawn(cfg)uint32_tCreate an agent. Returns id, or UINT32_MAX at capacity.
despawn(id)voidRemove an agent.
alive_count()uint32_tNumber of live agents.
tick_count()uint32_tTicks since engine creation.
set_group(id, gid)voidAssign to faction 1..63; 0 = none.

get_group_agents(gid, out, n)uint32_tList members of a faction.
agents_near(x, y, r, out, n)uint32_tSpatial query, sorted by distance.

Perception

Push world state into agents' senses. Sixteen built-in percept types plus 64 reserved custom slots.

perceive(id, type, data, len)voidPush one percept to one agent.
perceive_batch(entries, n, data)voidBulk push to many agents from one flat buffer.

Built-in percept types

Actions & decisions

register_action(name, tags)uint32_tMap a game action to a tag bitmask.
get_decision(id)DecisionSelected action + confidence + target.
report_outcome(id, reward, ΔE)voidFeed reward + energy delta. Drives DA learning.
record_help / harm / betrayalvoidUpdate social-graph edges.
nudge(id, tags, strength)voidSoft bias toward tag-matching actions.
explain(id)ExplanationPer-module contribution to last decision.

Action tags

TAG_MOVEMENT · TAG_RESOURCE · TAG_SOCIAL · TAG_COOPERATIVE · TAG_AGGRESSIVE · TAG_DEFENSIVE · TAG_SURVIVAL · TAG_CREATIVE · TAG_INVESTIGATIVE · TAG_ROUTINE · TAG_COMMUNICATION · TAG_LEISURE. Combine with |.

Operations

Save & load

save(path), load(path) for the full engine. save_agent, load_agent for one NPC.

Events

subscribe(mask, cb) for spawns, deaths, action changes, emotion shifts. Or poll_events() after each tick.

Runtime tuning

set_param(id, key, val) - 14 named parameters (baselines, learning rate, exploration, discount, decay), per agent or globally.

Profiling & logging

get_tick_profile() returns per-module microseconds. set_log_callback() routes internal logs out.
