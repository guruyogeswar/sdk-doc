Examples

Five end-to-end snippets - minimal loop, town scenario, dialogue context, Python, and Unity. The full source for each ships in sdk/examples/ and inside the release tarball.

Minimal game loop

One agent, ten ticks. The smallest LIMBIC program.

examples/basic_usage.cpp C++#include "limbic/limbic_engine.hpp"
using namespace limbic::sdk;

int main() {
    EngineConfig cfg;
    cfg.preset     = Preset::COGNITIVE;
    cfg.max_agents = 100;
    cfg.seed       = 42;
    auto engine = LimbicEngine::create(cfg);

    engine.register_action("patrol", TAG_MOVEMENT | TAG_ROUTINE);
    engine.register_action("forage", TAG_RESOURCE | TAG_SURVIVAL);
    engine.register_action("trade",  TAG_SOCIAL   | TAG_COOPERATIVE);
    engine.register_action("fight",  TAG_AGGRESSIVE | TAG_MOVEMENT);
    engine.register_action("rest",   TAG_ROUTINE  | TAG_SURVIVAL);

    AgentConfig ac{ .x=100, .y=100, .personality=Personality::MERCHANT };
    uint32_t npc = engine.spawn(ac);

    for (int i = 0; i < 300; ++i) {
        float energy = 0.8f, hunger = 0.3f;
        engine.perceive(npc, Percept::ENERGY_LEVEL, &energy, 1);
        engine.perceive(npc, Percept::HUNGER,       &hunger, 1);
        engine.tick(0.016f);

        Decision d = engine.get_decision(npc);
        engine.report_outcome(npc, /*reward=*/ 0.3f, 5.f);
    }
}

Town with three factions

Guards, merchants, bandits. Demonstrates groups, spatial queries, events, batch perception, save/load, and selective tick.

examples/game_scenario.cpp · excerpt C++// Spawn factions
for (int i = 0; i < 10; ++i) {
    uint32_t g = engine.spawn({ .x=50, .y=50, .personality=Personality::GUARD });
    engine.set_group(g, 1);   // guards
}
for (int i = 0; i < 20; ++i) {
    uint32_t m = engine.spawn({ .x=100, .y=100, .personality=Personality::MERCHANT });
    engine.set_group(m, 2);   // merchants
}

// Subscribe to deaths and emotion shifts
engine.subscribe(EVENT_AGENT_DIED | EVENT_EMOTION_SHIFT,
    [](const Event* ev, void*) {
        printf("event %u on agent %u tick %u\n",
               ev->type, ev->agent_id, ev->tick);
    }, nullptr);

// LOD pattern: tick only guards this frame
uint32_t guard_ids[64];
uint32_t n = engine.get_group_agents(1, guard_ids, 64);
engine.tick_agents(guard_ids, n, 0.016f);

// Save checkpoint
engine.save("town_state.bin");

Dialogue context for a quest NPC

One call returns tone, intent, relationship, top urgent need, and the four most emotionally-weighted shared memories. The intent (SEEK_HELP, ACCUSE, THANK, THREATEN, SOCIALIZE, …) is inferred from internal state - never authored.

dialogue.cpp C++auto ctx = engine.get_dialogue_context(npc, player);

switch (ctx.intent) {
    case Intent::SEEK_HELP:
        bark = "Please... I need " + std::string(ctx.top_need.name);
        break;
    case Intent::ACCUSE:
        bark = "You betrayed me. I haven't forgotten.";
        break;
    case Intent::SOCIALIZE:
        bark = (ctx.tone == Tone::FRIENDLY) ? "Good to see you!" : "...hey.";
        break;
}

Or feed the struct to an LLM prompt - tone, relationship, trust, top need, and recent shared memories produce grounded barks without hallucinated history.

Python - experiments and RL

my_experiment.py pythonfrom limbic import LimbicEngine, Preset, Personality, Percept

with LimbicEngine(preset=Preset.COGNITIVE, max_agents=100) as engine:
    npc = engine.spawn(x=50, y=50, personality=Personality.GUARD)
    engine.tick(0.016)
    d = engine.get_decision(npc)
    print(f"{d.action_name} (confidence: {d.confidence:.2f})")

Set LIMBIC_LIB to the path of liblimbic.so before running.

Unity - drop-in NPC

NpcBrain.cs C#using Limbic;

var engine = new LimbicEngine(new LimbicConfig {
    preset    = Preset.COGNITIVE,
    maxAgents = 100
});

uint npcId = engine.Spawn(new AgentConfig {
    x = 50, y = 50,
    personality = Personality.GUARD
});
engine.Tick(0.016f);
var d = engine.GetDecision(npcId);

Copy liblimbic.so or limbic.dll into the Unity project's Plugins/ folder. A LimbicNPC MonoBehaviour wrapper ships in sdk/bindings/unity/.
